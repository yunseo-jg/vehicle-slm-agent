# 아키텍처

10주차에 완성. 지금은 뼈대만.

## 구성 요소

| 구성 요소 | 위치 | 역할 |
|-----------|------|------|
| 온톨로지 | `ontology/` | 기능 사전. 스키마·초기 상태 생성 |
| MCP 도구 서버 | `tools/` | 도구 노출, 실행 |
| 시뮬레이터 | `sim/` | 차량 상태, 안전 검사 |
| 에이전트 | `agent/` | LangGraph. 의도 → 선택 → 검증 → 실행 → 응답 |
| 평가 | `eval/` | 평가셋, 실행기, 채점기 |
| 트레이싱 | Langfuse | 노드별 입출력 기록 |

## 모델 교체 지점

`agent.graph.build_graph(llm=...)` 하나. 도구 서버와 시뮬레이터는 모델과 무관.

## 도메인 교체

`ontology/vehicle.yaml`만 바꾸면 스키마·시뮬레이터가 따라온다. 도메인별 도구 구현(`tools/<domain>.py`)은 새로 써야 함.
